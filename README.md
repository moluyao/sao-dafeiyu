# 扫大肥鱼

一个在浏览器里玩的“扫雷”式小游戏：大肥鱼想干饭，Claude 拿着印章“禁止干饭”。

- **关卡模式：** 早饭 → 午饭 → 下午茶 → 晚饭 → 夜宵（Boss 关），每顿都可以直接选。
- **♾ 无限自助：** 回转饭桌一直在转，越转越快。没吃的米算浪费，看你能坚持几盘。
- **操作：** 左键开碗，右键或长按贴封条。数字表示周围有几个 Claude。
